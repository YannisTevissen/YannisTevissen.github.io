# yannistevissen.fr

Personal site built with [Astro](https://astro.build/) and deployed as static HTML to GitHub Pages.

The site is generated from `src/`, static assets live in `public/`, and GitHub Actions builds `dist/` before publishing it.

## Pages

| Path                                                                        | Purpose                                                  |
| --------------------------------------------------------------------------- | -------------------------------------------------------- |
| `/`                                                                         | About, research focus, selected work, bio                |
| `/research/`                                                                | Interests, publications, artifacts, teaching & mentoring |
| `/blog/`, `/blog/<year>/<slug>/`                                            | Notes, press, talks; MDX posts                           |
| `/advocacy/`                                                                | Disability and accessibility advocacy                    |
| `/contact/`                                                                 | Email, profiles                                          |
| `/cv/`                                                                      | Resume                                                   |
| `/talks/`, `/publications/`, `/artifacts/`, `/students/`, `/selected-work/` | Noindex redirects kept for old links                     |
| `/404.html`                                                                 | Custom not-found page                                    |

## Structure

- `src/pages/` - Astro routes.
- `src/layouts/` - Shared page layouts.
- `src/components/` - Header and footer.
- `src/content/blog/` - MDX blog posts with typed frontmatter.
- `src/content.config.ts` - Blog schema.
- `src/lib/site.ts` - Site URL, nav, social links, CV path, analytics ID.
- `src/pages/atom.xml.ts` - Atom feed generated from blog posts.
- `public/` - Static assets copied as-is into the build.
- `public/robots.txt` - Search crawler rules and sitemap pointer.
- `public/CNAME` - Custom domain for GitHub Pages.

## Content Updates

1. Create `src/content/blog/<YYYY-MM-DD>-<slug>.mdx` with frontmatter (see existing post for the schema).
2. Set `customSlug` for the public URL, for example `2026/physical-ai-reachy-smolvla`.
3. The Atom feed and sitemap update on next build.

CV PDF:

- File: `public/assets/cv/CV_YannisTevissen_en.pdf`
- Public URL: `/assets/cv/CV_YannisTevissen_en.pdf`

Images and video:

- Keep listing thumbnails small.
- Compress large blog images before committing.
- Prefer fast-start MP4 for videos (`moov` atom at the beginning).

## SEO

The Astro build emits:

- Canonical URLs based on `https://yannistevissen.fr`.
- Open Graph and Twitter card tags from `BaseLayout`.
- Blog post JSON-LD from `BlogPostLayout`.
- `sitemap-index.xml` and `sitemap-0.xml` from `@astrojs/sitemap`.
- `atom.xml` from the blog content collection.

Noindex redirect pages are intentionally excluded from the sitemap in `astro.config.mjs`.

Before deploying, run:

```bash
npm run astro -- check
npm run build
```

After deploying, verify:

```bash
curl -I https://yannistevissen.fr/
curl -s https://yannistevissen.fr/robots.txt
curl -s https://yannistevissen.fr/sitemap-index.xml
curl -s https://yannistevissen.fr/sitemap-0.xml
```

Check that robots points to `https://yannistevissen.fr/sitemap-index.xml`, and sitemap URLs use `https://yannistevissen.fr`, not the GitHub Pages hostname.

## Deployment

Deployment is handled by `.github/workflows/deploy.yml`.

On pushes to `main` or `master`, GitHub Actions:

1. Installs dependencies with `npm ci`.
2. Builds the static site with `npm run build`.
3. Uploads `dist/` as an artifact.
4. Publishes `dist/` to GitHub Pages with `JamesIves/github-pages-deploy-action`.

GitHub Pages should be configured to serve the branch generated by the deploy action, normally `gh-pages`, from the repository root.

Manual deploy path:

```bash
git status
npm run astro -- check
npm run build
git add .
git commit -m "Migrate site to Astro"
git push origin HEAD:master
```

Then watch the `Deploy site` workflow in GitHub Actions. Once it completes, re-run the post-deploy checks above.
